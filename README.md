## Descripción

Este repositorio contiene la solución del Laboratorio #3 del curso IE-0117 Programación Bajo Plataformas Abiertas.

Durante el desarrollo del laboratorio se implementaron diferentes programas en lenguaje C enfocados en el uso de:

- Funciones
- Estructuras de control
- Validación de datos
- Arreglos bidimensionales
- Estructuras (`struct`)
- Enumeraciones (`enum`)
- Manejo de matrices binarias
- Clasificación de sensores

Además, se utilizó Git y GitHub para el control de versiones, creando un branch independiente para cada ejercicio y posteriormente integrándolos a la rama principal (`main`).

## Contenido

- `ejercicio1.c`
  - Cálculo de potencias enteras
  - Validación de entradas
  - Verificación de número par/impar

- `ejercicio2.c`
  - Análisis de matrices binarias
  - Matriz identidad
  - Generación aleatoria de matrices

- `ejercicio3.c`
  - Clasificación de lecturas de sensores
  - Conteo por estado
  - Detección de lectura extrema
